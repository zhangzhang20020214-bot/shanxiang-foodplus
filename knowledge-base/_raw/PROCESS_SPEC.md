# 食养指南 → Markdown 知识库整理规范（v1.0）

## 任务目标
把一份中文官方「食养指南」PDF 的提取文本，转换为结构化 Markdown，供 Dify RAG 膳食知识库使用。一份文档对应一个 .md 输出文件。

## 输入输出
- 输入：原文提取文本（UTF-8，PyMuPDF 提取，中文/数字/单位完整），形如 `_raw/<文件名>.txt`，每页以 `===== 第N页 =====` 分隔。
- 参考模板（**必须先 Read 并严格模仿其格式**）：`D:/0-codex-project/demo1-食享/knowledge-base/processed/成人高血压食养指南.md`
- 输出：`D:/0-codex-project/demo1-食享/knowledge-base/processed/<文件名>.md`

## 格式规范（严格照模板）

1. **文件头 YAML frontmatter**，字段：
   - `title`（指南全名，含年版）、`source_doc`（原始 pdf 文件名）、`publisher`（发布机构）、`disease`（疾病类型）、`doc_type`（官方食养指南）、`version`（如 2023年版 / 2026年版）、`year`、`tags`（3-6 个关键词）。
   - 发布机构从封面（第1页）读取，通常为「国家卫生健康委办公厅」，以封面实际为准。
2. **紧跟一段 `> **处理说明**：` blockquote**，说明：过滤了哪些内容；保留 `*` 标记含义（`*` = 食药物质）。
3. **正文层级**用 `#`（文档标题）、`##`（一级章节）、`###`（二级小节）、`####`（食谱单套）。章节顺序固定为：
   1. 疾病概述与中医分型（前言精简为「指南说明」+ 疾病定义一句话 + 中医证型完整列出）
   2. 食养原则和建议（逐条列出，保留全部具体数值建议）
   3. 食物选择（十类/分类食物推荐量，逐条）
   4. 常见食物交换表（表格）
   5. 地区/证型食谱示例（食谱）
   6. 食养方举例（各证型食养方）

## 过滤规则（重要）

- **删除**：封面、目录、页眉页脚、页码。
- **删除**：附录中属于「纯医学分级 / 诊断标准 / 判定标准 / 分期标准 / 身体活动强度系数」的疾病分类内容（对应高血压版的「附录5 高血压水平分级」）。
- **保留**：前言（精简）、疾病定义、中医证型、食养原则、食物选择、食物交换表、食谱、食养方，以及**一切涉及饮食干预 / 食材推荐 / 禁忌 / 营养管理的附录**（例如高尿酸血症的「附录1 常见食物嘌呤含量」、慢性肾脏病的「分期营养管理原则」中饮食相关部分）。
- 判断原则：**与「吃什么、吃多少、怎么吃」有关的保留；与「怎么诊断、怎么分级、判定标准」有关的过滤。**
- **保留 `*` 标记**：原文标注食药物质的 `*` 原样保留（如 `黄芪*5g`），不得删除。

## 准确性要求（最高优先级，违反即返工）

1. **所有数字、单位必须与原文完全一致**：g、mg、ml、kcal、mmHg、μg、kg/m² 等，禁止改动、四舍五入、漏项、增项。
2. **PDF 表格 → 标准 Markdown 表格**，表头与列数正确，禁止错位、串列。多值单元格用「、」连接（如「馒头约半个、米饭半碗」）。
3. **食谱逐道菜转录**，每一道菜名、每一个克数都要完整，格式：`- **早餐**：菜名（材料 X g，材料 Y g）、菜名（…）；**中餐**：…；**全天总用量**：植物油 X g，盐 X g`。有「加餐/茶饮/午餐」的照原样保留该标签。
4. 表格下方的「注：」、食谱末尾的「注：」原文保留为 blockquote。

## 步骤
1. `Read` 参考模板（高血压版），吃透格式。
2. `Read` 输入原文提取文本（可分段多次读）。
3. 逐章节转录生成 Markdown。
4. `Write` 输出文件。

## 完成报告（在最终回复中给出）
- 输出文件绝对路径、总行数。
- 覆盖的章节清单（哪些保留、哪些过滤）。
- 你在原文中发现的**任何疑似提取异常**（可疑的 `*` 位置、数字不连续、乱码、缺页等），逐条列出供人工复核，宁多勿漏。
